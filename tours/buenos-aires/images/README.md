# Buenos Aires tour photo sources

Photos are stored locally and referenced by each chapter in `tour.json`. Source records below and in `sources.json` preserve authorship, source URLs, licenses, modifications, dimensions, and file hashes.

Photos are optimized JPEGs with a maximum width of 1600 pixels. They use a 4:3 frame so the complete subject and any required visible attribution remain within the carousel. Original aspect ratios are preserved inside the frame, with a softly blurred copy of the photograph filling any remaining space. No image content was generated.

## Source rights notes

Cueros Antílope and Floralis Genérica photos whose reuse permissions were not established have been removed from this tour and its catalog. Those chapters currently have no photos.

All remaining photographs are CC0, public domain, or under the Creative Commons licenses recorded below. Attribution-dependent files include visible author, license URL, and source-page credits; their adaptations retain the source license.
